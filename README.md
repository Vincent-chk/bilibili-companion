# 豆包陪看助手

豆包是一款陪你看 B 站的浏览器扩展。你看视频时，它会整理视频摘要、要点大纲和分段解读，方便你回顾内容、快速找到想看的部分。

当前 **0.2.0** 为本地验收构建，尚未发布。现阶段以 macOS 上的 Chrome 155 或更新版本为主要使用环境；Windows 验证暂缓。

## 它能做什么

- **自动记笔记**：开始陪看后，观看视频达到设定时间，豆包优先使用中文字幕生成摘要和点评；没有有效字幕时可自动使用已配置的语音服务。新安装默认 10 秒，可在设置中调整。
- **按时间查看要点**：点大纲可跳到视频对应位置；点「AI 解读」可查看该段说明。
- **回顾视频**：摘要和分段解读使用完整字幕；其他转写节选最多展示前 200 条。完整、可验证的豆包语音转写可按句分页查看。
- **随时暂停或结束**：暂停后不再记录和启动后续任务，已开始的任务会完成。结束后记录保留一小时，超期会先征求你的清除确认。

## 开始使用

1. 准备 **Chrome 155 或更新版本**，以及开发者提供的扩展安装包。目前尚未在 Chrome 应用商店或 GitHub Releases 发布。
2. 按[安装与使用指南](docs/安装与使用.md)解压安装包，在 Chrome 扩展管理页加载包含 `manifest.json` 的文件夹。已经安装本机测试版的用户可按[操作手册](docs/Chrome应用商店发布操作手册.md)更新。
3. 在同一个 Chrome 中登录 B 站，点击页面上的豆包，填写你选择的模型服务提供的 **Base URL、Model ID 和 API Key**，测试连接后保存。
4. 播放视频，等待笔记生成；点击豆包和视频卡片查看摘要、大纲与分段解读。

模型服务由你自行选择和配置，可能按调用量收费。生成摘要后，豆包也可能提前生成多段解读，每个视频可能产生多次模型调用。

## 使用时需要知道

- 视频确实没有可用中文字幕且语音转写服务已配置、授权时，会自动处理。字幕请求遇到网络、登录或风控错误时，不会因此自动上传音频。
- 豆包 Agent Plan 模式会将完整音轨发送给所配置的第三方语音服务，当前限制为最长 15 分钟、25 MiB、最多双声道。这是项目限制，不是服务商上限；处理未观看内容可能剧透，识别及摘要调用可能消耗额度或产生费用。有效完整转写可供后续摘要复用，但重新生成不保证一定不上传音频；中断后计费状态不明或旧转写冲突时，需要你明确操作。
- 观看记录、摘要和模型配置保存在本机浏览器。生成笔记时，视频标题和字幕会发送给你配置的模型服务。详细说明见[隐私说明](PRIVACY.md)。
- AI 生成内容可能有误，重要信息请结合原视频核对。豆包陪看助手不是 B 站官方产品。
- 旧版本已经生成的摘要，可在视频详情中点击「重新生成」以使用更新后的整理方式。

## 遇到问题

没有看到豆包时，请确认扩展已启用并刷新 B 站页面。连接失败时，请检查模型服务地址、模型名称、密钥、权限和余额；修改配置后再测试连接。更多说明见[安装与使用指南](docs/安装与使用.md)。
