# 安装与使用

当前为 0.1.0 功能体验版，正式 Release 和 Chrome 应用商店版本尚未发布；安装包由开发者提供。下图是在 Chrome for Testing 中采集的实际扩展管理界面，图中版本号为验收版本；不同浏览器的按钮名称可能略有差异。

## 安装

1. 将提供的扩展 zip 解压到一个固定文件夹。不要直接选择 zip 文件，也不要在装好后删除或移动该文件夹。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 打开「开发者模式」，点击「加载未打包的扩展程序」（部分版本显示「加载已解压的扩展程序」）。
4. 选择**直接包含 `manifest.json` 的文件夹**，不要选外层文件夹。
5. 确认出现「豆包陪看助手」且右下角开关已开启。打开或刷新 B 站页面。

![扩展管理页面：右上角为开发者模式，左上角为加载按钮](images/chrome-extensions.png)

已有开发版本时，验收前先关闭原版本的开关，避免两只豆包同时出现。使用独立的浏览器资料进行验收，可以避免测试清除操作影响平时的陪看记录。

## 第一次使用

1. 在当前浏览器中登录 B 站，点击页面上的豆包或「开始陪看」。
2. 填写模型服务的 Base URL、Model ID 和 API Key，点击「测试连接」，成功后保存并激活。模型服务费用由你和所选服务商结算。
3. 播放有字幕的视频。新安装默认累计前台播放 10 秒后开始生成摘要；暂停播放或切到后台不累计有效观看时间。已保存过的观看阈值会保留，可在设置中自行调整。
4. 点击豆包打开面板；点击视频卡片查看摘要、点评和要点大纲。点击大纲跳到对应时间，点击「AI 解读」展开该段说明。
5. 在设置中可修改触发时间、暂停陪看、关闭气泡或结束会话。结束后记录保留一小时；超期会先要求确认，点击清除才删除记录。

暂停会停止记录和启动后续任务，已开始的生成仍会完成；恢复后继续处理队列。

ASR 是可选服务，只有无字幕视频经你确认后才下载音频并转写。本轮真实 ASR 验收按需求方要求暂缓。

摘要完成后会预先生成大纲的分段解读，以便点击时更快显示，因此一个视频可能产生多次模型调用；费用以你配置的服务商计费为准。

## 更新与卸载

扩展会定期检查 [GitHub Releases](https://github.com/Vincent-chk/bilibili-companion/releases/latest)。有新正式版时，面板显示链接，由你下载并自行更新；不会自动下载安装。

更新已解压的扩展时，保持安装文件夹路径不变，将新文件解压覆盖到该目录，再到扩展管理页面点击该扩展的刷新按钮。更新前可先结束陪看，避免打断正在生成的任务。卸载扩展会删除其本地数据。

## 常见问题

- 没出现豆包：检查扩展开关，刷新 B 站页面，并确认没有被设置为隐藏。
- 提示需要登录：在**安装扩展的同一个浏览器资料**中登录 B 站，再打开面板。
- 提示 Key 无效：进入设置，检查服务商、模型权限、余额和 Key；修改后重新尝试。
- 加载报找不到清单：选择的目录应直接包含 `manifest.json`。
- 模型响应较慢：生成耗时取决于模型和网络；当前页面可以继续观看，打开面板查看任务状态。
