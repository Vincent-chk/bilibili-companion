# 长视频摘要与分段解读修复验收

日期：2026-10-28。版本：0.0.2（不递增）。范围：Phase 3 MVP 功能修复，真实 ASR、Windows 本轮不验收。

## 问题核实

指定视频 BV1NrHw6zEjq 时长 21:12。原记录保存了全部 587 条 AI 字幕，最后一条结束于 1270.92 秒；原大纲却仅到 07:47，最后一个分段记录带 `truncated: true`。

“转写节选，前 200 条”仅用于详情页展示，不是摘要输入上限。实际问题是：大纲仅校验结构和数量，未检查长视频的前中后覆盖；分段输入超过 6000 字时直接截去尾部。

## 修复

- 有时间戳的长视频明确要求大纲概括全片；对大纲范围、顺序及前中后覆盖做校验，覆盖不足按现有机制重试一次，仍不完整则报告失败。
- 超长分段复用既有字幕分块整理方法，处理全部分块后合并解读；任一块输出为空则失败，避免缺少内容还显示成功。
- 旧 `truncated` 分段缓存再次打开时重做；完整缓存继续复用。没有细分时间戳的 ASR 全文回退保持原行为，避免强迫模型编造时间。
- 转写节选中解释“仅展示前 200 条，摘要和分段解读使用完整转写”。已保存的旧大纲通过“重新生成”更新。
